# Brutalist E-Commerce Hero

A modern **Brutalist-style E-Commerce Hero Section** built with clean UI principles, bold typography, sharp layouts, and responsive design.
This project focuses on creating a visually striking landing section suitable for fashion, streetwear, tech, or premium product brands.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/SauravKumar81/brutalist-e-commerce-hero.git
```

Navigate to the project folder:

```bash
cd brutalist-e-commerce-hero
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## 🖥️ Build for Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
